## §1 Style guide + glossary decisions

U1 glossary decisions applied and suite-pinned: تدریسیات, وضاحت, آپ, موک ٹیسٹ, مشق/مشقی, نمبر, مندرجہ ذیل (درج ذیل banned), em-dash banned inside sentences, Urdu punctuation (۔ ، ؟ ؛), verb-final restructuring, no calque. Arabic-specific decisions (brief §4 + coordinator adjudications; all flagged for owner confirmation in §8):

- **Root (Sarf) → مادہ** (generic singular; plural/oblique مادے, invariant — 55×). جڑ/جڑوں/جڑی/جڑیں banned in the root sense (103+ occurrences). Follows guide W20 (the Nahw/Sarf note decision) + the owner-era ARB-051..056 مادہ uses; the 98× جڑ majority came from unverified Phase 1 items. **EXCEPTION:** جڑے/جڑا/جڑتے (verb "connected") is a different word — KEPT (6 fields).
- **Root letters → اصلی حروف** (اصلی حرف already established, ARB-295); **root pattern → مادے کا نمونہ** (`جڑی نمونہ` → `مادے کا نمونہ`; double-کا fixed at merge: `کسی لفظ کے مادے کا نمونہ`, ARB-076).
- **Grammar → قواعد** (گرامر banned); **grammatical (case/role) → نحوی** (`گرامری حالت/کردار` → `نحوی حالت/کردار`, ARB-137..141 — case is a Nahw concept).
- **ضمیر masculine:** `کون سی ضمیر` → `کون سا ضمیر` (6×); agreement extended through possessives/verbs (`کی ضمیر` → `کا ضمیر`, `ہوتی/کرتی` → `ہوتا/کرتا` for pronoun subjects, ARB-364..376); حرف masculine (`کرتا/ہوتا` for ب/ل/ک). Feminine kept where genuinely feminine: ضمیریں (plural), صورت, نہی, کتاب, التی.
- **حرفِ جر** (izafat, dominant 27× + 7 normalized = 34×); **حرفِ X particle construction extended** at merge: حرفِ تاکید / حرفِ ندا / حرفِ عطف / حرفِ نصب (5 fields). Plural `حروف جر` kept. **حرف علت left WITHOUT izafat** (uniform 12× class — a letter type, distinct from the particle construction; suite-pinned).
- **Form → صورت** (dominant 93×; شکل/شکلیں/شکلوں → صورت/صورتیں/صورتوں, 10 fields at merge; مشکل untouched).
- **The definite article:** EN `'Al-'` glosses → ال (Tajweed precedent); `'ال-'` prefix notation KEPT where the prefix itself is the subject (ARB-030/085/095/098).
- **Dual → تثنیہ** (uniform 61×; مثنیٰ never occurs). **Feminine → مؤنث** (typo مونث fixed, ARB-067 Q+E). **Letter Ya → یا** (یاء normalized, ARB-063/077/155/161; ضیاء untouched — a different word). Letter names otherwise already in dominant short forms (واؤ، تا، الف، نون…); بے kept only as prefix (بے نام/بے جان/بے حد).
- **Quran → قرآن پاک** for prose references (ARB-436, ARB-476). **Bare قرآن KEPT** in word-form/root-family listings where قرآن is the cited word (ARB-445, ARB-449 — 3 fields, suite-pinned).
- **Huwa pronoun → ہو** (ARB-271 `ضمیر ہوا` fixed — ہوا reads as "air"); ہی for Hiya KEPT (established, context disambiguates).
- **Sciences as agents → بتاتا ہے / مطالعہ کرتا ہے** (`نحو ... پڑھتا ہے` → `بتاتا ہے`, guide W20). **کس چیز → کس کا / کیا / کس سے** (one legitimate `کس چیز` kept, ARB-098 — genuine "which thing" object).
- **Echo-gloss rule (U1 open question — DECIDED for this bank):** DROP a parenthetical gloss iff it merely restates the preceding term: `صرف (صرف)` (5×), `جملہ اسمیہ (اسمی جملہ)` / `جملہ فعلیہ (فعلی جملہ)` (12×), `(روٹ)`, byte-identical glosses (`کتاب (کتاب)`, `قلم (قلم)`, `الفاعل (الفاعل)`), `(حالت کے اختتام)` calque gloss, Latin glosses (`(the)`, `(definite)`, `(indefinite)`, `(feminine)`, `(preposition)`, `(a / an)`, `(case)`, `(Jama Mukassar)`, `(diptote)`). KEEP glosses that ADD meaning: Arabic-word meanings (`(اسکول)`, `(استاد)`), quoted-sentence translations (`(دو استاد آئے)`), disambiguation (`(مذکر)`/`(مؤنث)`, `(عورت)`), descriptions (`(پورا جملہ)`, `(نیم جملہ)`).
- **Latin split:** DROP Latin echo-glosses after em-dashes (`— house`, `— the book`, `— from/to/what/who/where/how`, `— writer`); KEEP byte-identical all transliterated Arabic forms (verb/dual/plural forms, quoted sentences, `-ta`/`-un` endings, `kitabun`, root-letter glosses `K-T-B`/`D-R-S`/`'-L-M`, `VSO`) — they mirror the English fields and ARE the tested material; never convert to Arabic script. `'-L-M` leading-apostrophe shape kept byte-identical (ARB-056).
- **"English" dropped from T7/T8 translation questions (22 items):** the English asks for the "English" meaning/translation, but the `_ur` options are Urdu sentences, so `انگریزی ترجمہ` misdirects in Urdu mode. Reframed as مطلب/ترجمہ questions (ARB-265, 391, 464..474, 483..492; precedent: ARB-463 already omitted it). Suite-pinned: zero انگریزی in any `_ur` field. Reversible if the owner prefers literal retention — flagged in §8.
- **مبتدا vs مبتدأ left per-item (NOT normalized):** مبتدا 46× vs مبتدأ 11× in a uniform ARB-068..072 cluster including المبتدأ forms. Normalizing would alter Arabic-script definite forms; the verbatim rule errs toward keeping. Suite-pinned to the cluster; owner to decide on uniformity (§8).
- **Kept bank conventions (flagged, not "fixed"):** درس for the verb Darasa (ambiguous with درس "lesson"); ہم for the pronoun Hum (collides with Urdu ہم "we"); unvowelled/variant Arabic forms per field (see §7); script variants per field (المدرسة vs المدرسہ, على vs علی, سعيد vs سعید, ھو/ھذا U+06BE vs ہو/ہذا, ۃ U+06C3 vs ة, علىٰ superscript alef).
- **U1 open questions for this bank:** echo-gloss divergence DECIDED above (§3.10 of the brief); Arabic-note Latin transliterations N/A (notes out of scope); glossary gaps decided above and flagged in §8.
